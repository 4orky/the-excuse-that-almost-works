A deterministic program that writes the one line a gamer texts the boss to skip work on GTA 6 launch week. It scores 14 hand-written excuses against the judge's brief — believability first, then humour from the excuse's own logic, hurried-text tone, and a fresh angle — and writes the winner to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
